## ✨ Key Features 
**건물 & 강의실 검색:** 강의실 번호나 건물 이름만 입력해도 위치와 층수를 빠르게 안내합니다.

**강의실간 이동시간 예상:** 연강 수업 시 건물 간 최적 이동 시간 및 동선을 계산해 줍니다.

**캠퍼스 건물정보 & 편의시설 안내:** 프린터, 자판기 등 복잡한 캠퍼스 내부의 시설 위치를 한눈에 확인 가능합니다.
